# Library Management System 📚

A comprehensive, fully object-oriented system designed to simulate a modern public or institutional library. This application manages a complete inventory of books, tracks library memberships, and handles real-time borrowing, returning, and tracking logistics using Python.

## ✨ Key Features

*   **Book Inventory Management:** Add, update, and search for books instantly by their Title, Author, or Unique ISBN.
*   **Member Database Management:** Create and manage unique library user profiles (Members) with their personal details and active status.
*   **Issue & Return Workflow:** A smooth check-out and check-in system that automatically updates the availability status of books.
*   **Dynamic Tracking:** Instantly view which books are currently available on the shelves and which ones are checked out by which member.

---

## 🛠️ OOP Concepts Implemented

This project is built from scratch to showcase high-quality software architecture using core **OOP principles**:
*   **Classes & Blueprints:** Structured using distinct real-world entities like `Book`, `Member`, and `Library`.
*   **Encapsulation:** Protects the inner database state, catalog arrays, and user information using private/protected variables, exposed safely via class methods.
*   **Composition:** The main `Library` system acts as a container that holds and manages multiple objects of `Book` and `Member` classes seamlessly.
*   **Constructors (`__init__`):** Used to dynamically set attributes like book availability, member registration timestamps, and unique IDs upon creation.
